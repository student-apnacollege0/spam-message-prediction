# Spam Message Prediction

## About the Project
In this project, I built a machine learning model to identify whether a message is spam or not spam.

## Tools Used
- Python
- Pandas
- NumPy
- Scikit-learn
- NLP
- Jupyter Notebook

## What I Did
- Collected and cleaned the data
- Preprocessed text messages
- Converted text into numerical data
- Trained a machine learning model
- Predicted whether messages are spam or not spam

## Project Objective
The main goal of this project is to detect spam messages and help users identify unwanted or fake messages.

## Conclusion
This project helped me learn about machine learning, text preprocessing, and Natural Language Processing (NLP).
